# hemlock_collembola

Data and analysis code for the project: Non-target effects of dinotefuran for elongate hemlock scale management in northeast Ohio.

Mills, A. C., S. F. Ward, and K. I. Perry. Non-target effects of dinotefuran used to control elongate hemlock scale (Fiorinia externa)

This project was funded by the Cleveland Metroparks Natural Resources Grant Program.
